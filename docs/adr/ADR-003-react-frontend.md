# ADR-003: React, Redux Toolkit y Axios

- **Estado:** aceptada por confirmación del solicitante.
- **Contexto:** la plantilla contenía referencias contradictorias a Angular.
- **Decisión:** React 19, TypeScript estricto, Redux Toolkit para estado compartido y Axios como límite HTTP.
- **Consecuencias positivas:** flujo explícito, tipado y componentes reutilizables.
- **Trade-offs:** Redux añade estructura que el MVP podría resolver con estado local/cache de servidor.
